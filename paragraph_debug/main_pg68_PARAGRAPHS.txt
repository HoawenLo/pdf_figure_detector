--- BLOCK 5 ---
15.2 Features to be used for establishing direction features
Only surfaces belonging to one of the following invariance classes shall be used to establish direction
features (see ISO 17450-1):
— revolute (e.g. a cone or a torus);
— cylindrical (i.e. a cylinder);
— planar (i.e. a plane).
